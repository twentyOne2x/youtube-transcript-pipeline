# Core Beliefs

Last reviewed: 2026-03-05

## Principles
- Reliability over velocity when safety or correctness is at risk.
- Small, reversible changes are preferred over broad risky rewrites.
- Documentation should reflect the current system, not intended future state.
- Tests and checks are part of the definition of done.

## Operating Defaults
- Keep plans current in `docs/plans/active/` and move completed items to `docs/plans/completed/`.
- Track unresolved quality gaps in `docs/plans/tech-debt-tracker.md`.
- Keep `AGENTS.md` concise and link out for detail.
